# 业务流程

> 最后验证：2026-09-24

本文描述 stock-ticker 的核心业务流：数据如何从数据源流向用户界面，刷新机制如何运转。

---

## 1. 端到端业务流

```
用户打开 VS Code
   │
   ▼
activate() ──► 创建 StockDataService
   │
   ├──► 创建状态栏项（右侧，优先级 100）
   ├──► 注册 3 个命令 + 2 个快捷键
   ├──► 首次 refresh()（立即拉取行情）
   └──► startTimer()（按 refreshInterval 定时刷新）
```

用户交互路径：

- 状态栏点击 / `Ctrl+Shift+V` / 命令 `showChart` → 打开分时图 Webview
- `Ctrl+Shift+R` / 命令 `refresh` → 手动刷新行情（force 模式，非交易时段也请求）
- 分时图内「刷新看板」按钮 / 命令 → 拉取看板数据
- 「问句管理」按钮 / 命令 `manageBoardQueries` → 打开问句管理 Webview

## 2. 行情数据流

```
定时器 / 手动命令
   │  refresh(force)
   ▼
isMarketOpen() 判断（非交易时段且非 force 且已有数据 → 直接返回）
   ▼
StockDataService.fetchQuote(signal)
   ├── Promise.all
   │   ├── GET http://d.10jqka.com.cn/v6/time/zs_1A0001/last.js  （上证，hexin-v）
   │   └── GET http://d.10jqka.com.cn/v6/time/zs_399001/last.js  （深证，hexin-v）
   ├── 解析 JSONP + 分时序列，合并两市成交额
   ├── 更新当日/前日累计成交额缓存（交易日切换时滚动）
   └── 返回 StockQuote
   ▼
renderStatusBar(q)  更新状态栏文字 + Tooltip
chartPanel.postMessage({ type: "quoteUpdated", data })   增量推送分时图
```

## 3. 看板数据流

```
手动刷新看板 / 问句保存 / 首次打开分时图 / 看板定时器（需开启且交易时段）
   │  refreshBoard()
   ▼
StockDataService.fetchBoardData(queries, customBoards)
   └── Promise.all（并行）
       ├── 6 个爱问财 POST（板块/个股 × 新高/新低/不创新低）
       └── N 个自定义问句 POST
   ▼
chartPanel.postMessage({ type: "boardUpdated", data })   增量推送看板
```

## 4. 刷新机制

| 路径 | 触发 | 交易时段限制 | 说明 |
|------|------|--------------|------|
| 行情定时器 | `refreshInterval` 秒（默认 1s） | 是（否则跳过） | 背压：上一请求在途则跳过本轮 |
| 手动刷新行情 | 命令 / `Ctrl+Shift+R` / 面板刷新按钮 | 否（force） | 抢占取消在途请求（AbortController） |
| 看板刷新 | 刷新看板按钮 / 问句保存 / 首次开图 | 否（手动不受限） | 默认不随行情定时刷新 |
| 看板定时器 | `boardRefreshInterval` 秒 | 是 | 需 `boardAutoRefresh=true` 才启动 |

## 5. 交易时段规则

- A 股交易时段（北京时间 UTC+8）：上午 **09:15–11:35**（含集合竞价余量）、下午 **12:55–15:05**
- 周末（周 0/6）不刷新
- 非交易时段：保留最后一次数据展示，不再发起请求
- 手动刷新（force）不受交易时段限制

## 6. 跨交易日成交额缓存

- `todayTurnoverByTime` / `prevDayTurnoverByTime`：Map<"HH:MM", 累计成交额(元)>
- 每次拉取时检测北京时间日期 `recordedDate`，变化则把当日缓存转入前日缓存并清空当日
- 两市成交额对比：取前日缓存中当前时刻（或最近时刻）的累计值

## 7. 系统边界

| 我们做什么 | 我们不做什么 |
|------------|--------------|
| 上证/深证指数实时行情与分时展示 | 交易、下单 |
| 板块/个股新高新低看板（爱问财动态查询） | 自选股管理 |
| 看板问句自定义与自动刷新 | 多市场（美股/港股）监控 |
| 两市成交额对比与交易时段感知 | 历史 K 线 |
