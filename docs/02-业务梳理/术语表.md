# 术语表

> 最后验证：2026-09-24

stock-ticker 涉及的领域术语速查。

| 术语 | 全称 / 含义 | 说明与示例 |
|------|-------------|------------|
| 上证指数 | 上证综指（代码 `1A0001`） | 状态栏展示的主标的 |
| 深证成指 | 深证成分指数（代码 `399001`） | 与上证并行拉取，用于两市成交额合计 |
| 分时图 | 日内价格随时间变化曲线 | 数据点为 `HH:MM,price,分钟额,均价,量` |
| 均价线 | 当日累计成交额/累计成交量 | 分时图第二曲线（数据第 4 列） |
| 昨收 | 前一交易日收盘价 | 涨跌幅基准：`(price - prevClose) / prevClose` |
| 涨跌额 | 当前价 - 昨收 | 状态栏 Tooltip 字段 |
| 涨跌幅 | 涨跌额 / 昨收 × 100% | 状态栏红涨绿跌 |
| 放量/缩量 | 两市成交额较前日同时刻的增减 | Tooltip 量比对比 |
| 新高/新低 | 标的创历史/区间新高、新低 | 默认问句：`创60日新高/新低的个股 非ST` |
| 板块 | 行业指数集合（中证行业指数 + 行业 ETF） | 由爱问财「同花顺行业」问句动态决定，不再硬编码 |
| 爱问财 | 同花顺自然语言选股问答平台（iwencai.com） | 看板数据源，POST 自然语言问句 |
| hexin-v | 同花顺 Chameleon 反爬指纹令牌 | 每次请求必须携带新生成的 hexin-v 请求头 |
| Chameleon | 同花顺浏览器指纹 SDK | `hexin-v.ts` 是其 Node.js 反混淆移植（@ts-nocheck） |
| JSONP | JSON with Padding | 同花顺分时接口的包裹格式（`…_last({JSON})`） |
| Webview | VS Code 内嵌浏览器视图 | 分时图与问句管理两个面板均为此类型 |
| 状态栏 | Status Bar，窗口底部信息栏 | 行情展示入口（右侧，优先级 100） |
| 增量更新 | 只推送变化数据、不整页重绘 | quoteUpdated / boardUpdated 两条独立消息 |
| 交易时段 | A 股可交易时间 | 09:15–11:35 / 12:55–15:05（北京时，周末除外） |
| 背压 | 上一请求在途时跳过本轮定时刷新 | `quoteInFlight` 标志位 |
| TOP 8 | 每组最多展示 8 项 | 看板按涨跌幅排序取前 8 |
| 问句 | 爱问财自然语言查询语句 | 4 个默认问句 + 自定义看板问句 |
| 自定义看板 | 用户新增的看板列表 | `{id, name, question}`，蓝色标识，最多 8 项 |
| vsix | VS Code 扩展安装包格式 | 打包产物 `stock-ticker-0.0.x.vsix` |
