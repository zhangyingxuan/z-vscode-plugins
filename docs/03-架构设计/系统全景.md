## 2. 模块关系

| 文件 | 职责 | 依赖 |
|------|------|------|
| `src/extension.ts` | 入口：状态栏、命令、定时器、Webview 管理、消息路由 | vscode API、StockDataService、两个 HTML builder |
| `src/services/stock-data.ts` | 数据获取与解析、HTTP、成交额缓存；导出类型 + StockDataService + DEFAULT_BOARD_QUERIES | node http/https、hexin-v |
| `src/services/hexin-v.ts` | 生成同花顺 Chameleon 指纹令牌 | 无（@ts-nocheck 自包含） |
| `src/components/chart-webview.ts` | 生成分时图 Webview HTML（内联数据、Canvas 绘制） | stock-data 类型 |
| `src/components/query-manager-webview.ts` | 生成问句管理 Webview HTML（表单 + 消息交互） | stock-data 类型 |
| `out/` | tsc 编译产物，`package.json#main` 指向 `./out/extension.js` | — |

## 3. 核心链路

1. **启动**：`activate()` → 建 service → 状态栏 → 注册命令 → `refresh()` 首拉 → `startTimer()`
2. **行情**：定时器/命令 → `refresh()` → `fetchQuote()` 并发拉上证+深证 → 状态栏渲染 + `quoteUpdated` 推送到分时图
3. **看板**：手动/定时 → `refreshBoard()` → `fetchBoardData()` 并行 4+N 个爱问财查询 → `boardUpdated` 推送
4. **问句管理**：`saveConfig` → 写用户配置 → `saved` 回执 → 重起看板定时器 → `refreshBoard()`

## 4. 关键设计决策

| 决策 | 原因 |
|------|------|
| 零第三方运行时依赖 | 扩展随 .vsix 分发；Canvas 绘制 + node 内置 http(s) 足够，控制体积与风险 |
| 增量更新（quoteUpdated / boardUpdated 分离） | 行情秒级、看板分钟级，避免低频看板刷新导致整页重绘 |
| 背压（quoteInFlight）+ 抢占取消（AbortController） | 手动刷新中断在途请求，避免慢网络堆积 |
| 看板问句动态化（不再硬编码 ~100 只标的） | 标的范围由爱问财问答决定，问句可在设置页自定义 |
| 动态列双保险提取（精确键名 + 子串匹配） | 爱问财列名随版本变化（如 `指数@涨跌幅:前复权[20260924]`） |
| 单例 WebviewPanel | 重复打开复用面板，避免多实例状态分裂 |
| 交易时段感知 + 定时刷新单例 | 非交易时段零请求；看板默认不自动刷新避免无谓请求 |
