# 构建与调试方案

> 最后验证：2026-09-24

stock-ticker 的构建、打包、调试流程与常见问题。

---

## 1. 目录说明

| 路径 | 说明 |
|------|------|
| `src/` | TypeScript 源码（不打入 vsix） |
| `out/` | tsc 编译产物；`package.json#main = ./out/extension.js` |
| `stock-ticker-0.0.x.vsix` | vsce 打包产物，位于 stock-ticker 根目录 |
| `.pnpm-store/` | pnpm 本地缓存（gitignore/.vscodeignore 均排除） |

## 2. npm scripts

| script | 命令 | 用途 |
|--------|------|------|
| `compile` | `tsc -p ./` | 编译到 out/ |
| `watch` | `tsc -watch -p ./` | 增量编译（调试时运行） |
| `lint` | `eslint src --ext ts` | 静态检查 |
| `package` | `npx vsce package` | 打包 vsix |
| `build` | `compile && package` | 编译 + 打包 |
| `vscode:prepublish` | `npm run compile` | 发布前钩子 |

## 3. 打包（vsce）

- `.vscodeignore` 排除：`src/**`、`*.ts`、`*.map`、`.vscode/**`、`node_modules/**`、`.pnpm-store/**`、`*.vsix`
- 产物：`stock-ticker-{version}.vsix`（如 0.0.3 → 46.9KB）
- publisher：`blowsysun`；engines.vscode：`^1.74.0`

## 4. 调试（F5）

- `.vscode/tasks.json`：默认构建任务 = `npm watch`（tsc 增量编译，`$tsc-watch` problemMatcher）
- `.vscode/launch.json`：`Run Extension` 配置
  - `type: extensionHost`，`--extensionDevelopmentPath=${workspaceFolder}`
  - `outFiles: ${workspaceFolder}/out/**/*.js`，`preLaunchTask: ${defaultBuildTask}`
- 流程：F5 → 自动 watch 编译 → 打开 Extension Development Host，断点可打在 src/*.ts（sourceMap 已开启）

## 5. 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| F5 启动报找不到模块 | 未先 watch 编译，out/ 缺失；tasks.json 默认构建任务会自动触发 |
| 打包后功能缺失 | 检查 `main` 指向 out/ 且 out/ 已最新；src/** 不进 vsix 是预期行为 |
| vsce 打包失败 | 检查版本号唯一、README/CHANGELOG 存在性要求 |
| 编辑器提示类型错误 | 遵守 tsconfig strict；hexin-v.ts 为 @ts-nocheck 不受影响 |
| 网络请求全部失败 | 检查系统代理/VPN 是否拦截 `d.10jqka.com.cn` 与 `iwencai.com` |
