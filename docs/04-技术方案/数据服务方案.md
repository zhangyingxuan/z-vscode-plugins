# 数据服务方案

> 最后验证：2026-09-24

stock-ticker 的数据采集与认证方案：hexin-v 指纹、同花顺/爱问财请求、超时取消、缓存与常见问题。接口参数细节见 `05-API文档/外部数据接口.md`。

---

## 1. hexin-v 指纹认证

- 同花顺接口（含爱问财）要求请求头携带 `hexin-v` 令牌，由同花顺 Chameleon 浏览器指纹 SDK 生成
- `src/services/hexin-v.ts` 是该 SDK 的反混淆移植（Node.js 可用版），文件头部 `@ts-nocheck`
- 导出 `createV()`，**每次请求调用生成新令牌**，不得缓存复用（令牌与时间、指纹绑定，复用会被拒）
- 注入位置：`thsHeaders()` / `iwcHeaders()` 两个私有方法

要点：不要改造 hexin-v.ts 的类型或逻辑；它是原样移植，改动风险高且无收益。

## 2. 同花顺行情请求

- 路径：`StockDataService.THS_LINE_BASE` = `http://d.10jqka.com.cn/v6/time`（**HTTP 非 HTTPS**）
- 每次并发拉取两个指数：`zs_1A0001`（上证）、`zs_399001`（深证）
- JSONP 包裹格式：`quotebridge_v6_time_zs_{code}_last({JSON})`，用首个 `(` 与末个 `)` 剥壳
- 分时序列以分号分隔，每点 `HHMM,price,分钟成交额,分钟均价,分钟成交量`
- 解析容错：对象键兼容 `zs_`/`hs_`/裸 code 前缀；非法点（价格非正）跳过
- 两市成交额 = 上证累计 + 深证累计

## 3. 爱问财查询请求

- 路径：`https://www.iwencai.com/unifiedwap/unified-wap/v2/result/get-robot-data`
- **必须表单编码**（`application/x-www-form-urlencoded`），JSON 编码会被服务端拒绝
- 关键 body 字段：`source=Ths_iwencai_Xuangu`、`version=2.0`、`question`（问句）、`perpage`（看板 50）、`secondary_intent`（板块 `zhishu` / 个股 `stock`）
- 响应提取路径：`data.answer[0].txt[0].content.components[0].data.datas`
- 字段动态列（如 `指数@涨跌幅:前复权[20260924]`）：`pickString`/`pickNum` 先精确键名匹配，再按子串匹配兜底
- 失败降级：解析异常返回空数组，看板显示为空而非报错（`fetchBoardItems` try/catch + `fetchIwencai` JSON 解析兜底）

## 4. HTTP 层

- `fetchHttp`：基于 node `http`/`https` 模块，按 URL 协议选择
- 超时 **10s**（`options.timeout`），超时 `req.destroy()` 抛「请求超时」
- `AbortSignal` 支持：手动刷新通过 `quoteAbort` 抢占取消在途请求
- 非 2xx 状态码直接拒绝

## 5. 成交额缓存（跨交易日滚动）

| 字段 | 作用 |
|------|------|
| `todayTurnoverByTime` | 当日两市分时累计成交额，key=`HH:MM` |
| `prevDayTurnoverByTime` | 前一交易日同结构缓存 |
| `recordedDate` | 当前记录交易日（北京时间 YYYY-MM-DD） |

- 每次 `fetchQuote` 检测日期变化：当日缓存 → 前日缓存，清空当日
- 对比值取法 `findInMap`：精确时刻不存在时取最近早于当前时刻的记录
- 成交量/成交额输入单位为**元**，展示格式化 `formatTurnover`

## 6. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 行情一直不更新 | 非交易时段 / 周末（预期行为） | 手动刷新（force）验证 |
| 看板为空 | 爱问财查询失败（被降级为 `[]`） | 查看 `[stock-ticker] 爱问财看板查询失败` 日志 |
| 请求被拒 / 429 | hexin-v 过期或复用；请求频率过高 | 每次请求新生成令牌；降低刷新频率 |
| 爱问财字段缺失 | 列名随版本变化 | 检查 `pickString`/`pickNum` 候选键是否需要补充 |
| JSONP 解析失败 | 同花顺接口变更 | 检查剥壳逻辑与响应结构 |
