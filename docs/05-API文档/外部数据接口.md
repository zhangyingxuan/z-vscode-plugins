# 外部数据接口

> 最后验证：2026-09-24

stock-ticker 调用的两个外部数据接口完整定义。实现细节见 `04-技术方案/数据服务方案.md`。

---

## 1. 同花顺分时行情（JSONP）

### 请求

```
GET http://d.10jqka.com.cn/v6/time/zs_{code}/last.js
```

| 参数 | 值 | 说明 |
|------|-----|------|
| `code` | `1A0001`（上证指数）/ `399001`（深证成指） | 两个指数每次并行拉取 |

请求头（`thsHeaders`）：

| Header | 值 |
|--------|-----|
| `hexin-v` | `createV()` 新生成令牌（必带） |
| `Referer` | `http://q.10jqka.com.cn/` |
| `User-Agent` | Chrome 105 UA |
| `X-Requested-With` | `XMLHttpRequest` |

### 响应

JSONP 包裹：`quotebridge_v6_time_zs_{code}_last({JSON})`，用首 `(` 与末 `)` 剥壳。

```json
{
  "zs_1A0001": {
    "pre": 3285.45,
    "data": "0930,3280.12,1234567.89,3280.50,100000;0931,3281.00,…",
    "isTrading": true,
    "date": "20260924"
  }
}
```

`data` 分号分隔分钟点，每点格式：`HHMM,price,分钟成交额,分钟均价,分钟成交量`（均为字符串）。对象键兼容 `zs_`/`hs_`/裸 code 前缀。

## 2. 爱问财自然语言查询（POST）

### 请求

```
POST https://www.iwencai.com/unifiedwap/unified-wap/v2/result/get-robot-data
Content-Type: application/x-www-form-urlencoded   ← 必须表单编码，JSON 会被拒
```

body 字段：

| 字段 | 值 | 说明 |
|------|-----|------|
| `source` | `Ths_iwencai_Xuangu` | 固定 |
| `version` | `2.0` | 固定 |
| `question` | 问句（如 `同花顺行业新高`） | 4 默认问句 + 自定义看板问句 |
| `perpage` | `50`（看板）/ `100`（默认） | 分页大小 |
| `page` | `1` | 当前页 |
| `secondary_intent` | `zhishu`（板块）/ `stock`（个股） | 查询类型 |
| `query_area` / `block_list` | 空 | 固定 |
| `log_info` | `{"input_type":"typewrite"}` | 固定 |
| `add_info` | `{"urp":{…},"contentType":"json","searchInfo":true}` | 固定 |
| `source_from` | `self` | 固定 |

请求头（`iwcHeaders`）：`hexin-v` 新令牌、`Referer: https://www.iwencai.com/`、`Origin: https://www.iwencai.com`、UA、`X-Requested-With`。

### 响应提取路径

```
data.answer[0].txt[0].content.components[0].data.datas   （数组）
```

### 动态列名（双保险提取）

爱问财列名随版本变化（可能带日期后缀，如 `指数@涨跌幅:前复权[20260924]`）：

| 目标字段 | 精确键候选 | 子串候选 |
|----------|-----------|----------|
| 名称 | `股票简称` `指数简称` `板块名称` `行业名称` `名称` `name` | — |
| 代码 | `股票代码` `指数代码` `行业代码` `板块代码` `代码` `code` | — |
| 价格 | `最新价` `收盘价` | `收盘价` |
| 涨跌幅 | `最新涨跌幅` `涨跌幅` `涨幅(%)` `涨幅` | `涨跌幅` |

### 降级策略

- JSON 解析失败 → 返回空数组
- `fetchBoardItems` 异常 → console.warn + 返回 `[]`（看板显示空，不中断页面）

## 3. 认证：hexin-v

- 生成：`createV()`（`src/services/hexin-v.ts`，Chameleon SDK 的 Node.js 移植）
- 规则：**每个请求新生成**，不得复用；缺失/过期会被反爬拒绝

## 4. HTTP 通用行为

- 超时：10s（超时 destroy + 抛错）
- 取消：支持 `AbortSignal`（手动刷新抢占取消在途请求）
- 非 2xx：拒绝并抛 `HTTP {code}`
