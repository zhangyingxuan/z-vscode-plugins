# 数据模型

> 最后验证：2026-09-24

stock-ticker 的内部数据模型（TypeScript 类型）与配置项 schema。定义于 `src/services/stock-data.ts`。

---

## 1. StockQuote（实时行情）

| 字段 | 类型 | 说明 |
|------|------|------|
| `price` | number | 当前价格 |
| `changePercent` | number | 涨跌幅（%） |
| `changeAmount` | number | 涨跌额 |
| `prevClose` | number | 昨日收盘价 |
| `open` | number | 今日开盘价 |
| `high` / `low` | number | 今日最高/最低价 |
| `turnover` | number | 两市成交额（元） |
| `prevTurnover` | number | 前一交易日同时刻成交额（元），0=暂无 |
| `trends` | Array<[string, number, number, number]> | 分时点 `[时间, 价格, 均价, 成交量]` |

来源：上证指数为准（price/trends 取自 1A0001），turnover = 两市累计之和。

## 2. BoardData / BoardItem（看板）

```ts
interface BoardData {
  sectors: { newHigh: BoardItem[]; newLow: BoardItem[] };
  stocks:  { newHigh: BoardItem[]; newLow: BoardItem[] };
  custom:  Array<{ title: string; items: BoardItem[] }>;
}

interface BoardItem {
  code: string;         // 证券代码（可能为空）
  name: string;
  price: number;
  changePercent: number; // 涨跌幅（%）
}
```

展示规则：每组按涨跌幅排序取 TOP 8。

## 3. CustomBoard（自定义看板）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 稳定唯一 id（编辑/删除定位） |
| `name` | string | 看板显示名称 |
| `question` | string | 爱问财问答语句 |

## 4. BoardQueries（看板问句）

```ts
interface BoardQueries {
  sectorHigh: string;  // 板块新高
  sectorLow:  string;  // 板块新低
  stockHigh:  string;  // 个股新高
  stockLow:   string;  // 个股新低
}

DEFAULT_BOARD_QUERIES = {
  sectorHigh: "同花顺行业新高",
  sectorLow:  "同花顺行业新低",
  stockHigh:  "创60日新高的个股 非ST",
  stockLow:   "创60日新低的个股 非ST",
};
```

## 5. 配置项 schema（package.json contributes.configuration）

| 键 | 类型 | 默认值 | 说明 |
|----|------|--------|------|
| `stock-ticker.refreshInterval` | number | 1 | 行情刷新间隔（秒），交易时段内生效 |
| `stock-ticker.boardAutoRefresh` | boolean | false | 看板自动刷新开关 |
| `stock-ticker.boardRefreshInterval` | number | 300 | 看板自动刷新间隔（秒） |
| `stock-ticker.boardQueries` | object | DEFAULT_BOARD_QUERIES | 4 个默认问句 |
| `stock-ticker.customBoards` | array | `[]` | 自定义看板 `{id, name, question}` |

扩展侧容错：`getBoardQueries` 缺省项回退默认值；`getCustomBoards` 过滤缺 id/name/question 的无效项。

## 6. 内部结构（非导出）

| 名称 | 说明 |
|------|------|
| `ParsedIndexData` | 解析后的指数数据（含 `cumAmounts: [时间, 累计成交额]`） |
| `todayTurnoverByTime` / `prevDayTurnoverByTime` | 成交额缓存 Map<"HH:MM", 元>，交易日切换滚动 |
| `recordedDate` | 已记录交易日（北京时间 YYYY-MM-DD） |
