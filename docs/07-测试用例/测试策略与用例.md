# 测试策略与用例

> 最后验证：2026-09-24

stock-ticker 的测试策略：无自动化单测（现状），以手动测试为主。用例按功能分层编号。

---

## 1. 测试分层

| 层 | 手段 | 覆盖 |
|----|------|------|
| 单元 | 无（零运行时依赖，逻辑集中于数据解析） | — |
| 集成 | 手动 + Extension Host（F5 调试窗口） | 真实数据源联通 |
| UI | 手动（真实 VS Code 安装） | 状态栏、Webview 渲染 |
| 回归 | 发布前清单（见 §3） | 全功能 |

> 备注：数据源（同花顺/爱问财）受交易时段与反爬限制，自动化测试环境不稳定，手动测试为权威手段。

## 2. 手动用例

### 状态栏（TC-01 ~ TC-03）

**TC-01 行情显示**：前置：交易时段内启动。步骤：观察状态栏。预期：显示 `▲/▼ 上证 {价格} {涨跌幅}%`，上涨红色、下跌绿色。

**TC-02 悬浮详情**：步骤：悬停状态栏项。预期：Tooltip 含开盘、昨收、最高、最低、两市成交额、量比对比。

**TC-03 点击打开分时图**：步骤：点击状态栏项。预期：分时图面板打开；再点关闭。

### 分时图（TC-04 ~ TC-06）

**TC-04 Canvas 渲染**：步骤：`Ctrl+Shift+V` 打开。预期：分时线红涨绿跌渐变、昨收虚线、网格、右侧价格标签、底部时间轴、当前价圆点。

**TC-05 自适应与高 DPI**：步骤：调整窗口大小、切换屏幕缩放。预期：图表按窗口重绘，标签不溢出。

**TC-06 增量更新**：步骤：保持面板打开，等待 ≥2 个刷新周期（refreshInterval=1s）。预期：价格/曲线平滑更新，无整页闪烁重载。

### 看板（TC-07 ~ TC-08）

**TC-07 默认看板**：步骤：打开分时图，等待看板加载。预期：板块/个股各自新高、新低、不创新低三组，每组 ≤8 项且按涨跌幅降序。

**TC-08 自定义看板**：步骤：问句管理 → 新增自定义问句（如 `涨幅大于5%的股票`），下拉选择模块（板块/个股）→ 保存。预期：看板页对应模块区域出现蓝色标识的自定义列表，≤8 项；可编辑/删除/改模块。

### 问句管理（TC-09 ~ TC-10）

**TC-09 修改问句生效**：步骤：修改某默认问句 → 保存。预期：收到「已保存」，看板立即按新问句刷新；配置项持久化。

**TC-10 恢复默认**：步骤：点「恢复默认」。预期：4 个问句恢复为默认值并生效。

### 交易时段（TC-11 ~ TC-12）

**TC-11 盘后停止刷新**：步骤：非交易时段观察（可改系统时区模拟）。预期：保留最后一次数据，无新请求。

**TC-12 手动刷新不受限**：步骤：盘后按 `Ctrl+Shift+R`。预期：仍发起请求并更新数据。

### 异常（TC-13）

**TC-13 网络失败降级**：步骤：断开网络后打开分时图。预期：不崩溃；看板区域为空/提示；恢复网络后手动刷新成功。
