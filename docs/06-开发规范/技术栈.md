# 技术栈

> 最后验证：2026-09-24

stock-ticker 的技术选型与精确版本。

---

## 1. 技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 语言 | TypeScript | ^5.3.0 | devDependency |
| 宿主 | VS Code API | ^1.74.0（engines.vscode） | @types/vscode ^1.74.0 |
| 运行时 | Node.js | ^18.0.0（@types/node） | 运行于 VS Code 内置 Node |
| 打包 | @vscode/vsce | ^3.0.0 | vsix 打包 |
| 依赖策略 | 运行时依赖 | **空（零第三方）** | dependencies 必须为空 |

## 2. tsconfig 约定（`stock-ticker/tsconfig.json`）

| 选项 | 值 | 影响 |
|------|-----|------|
| `module` | commonjs | 不得写 ESM-only 语法 |
| `target` / `lib` | ES2020 | 不得用超 ES2020 的运行时特性 |
| `strict` | true | 全量严格模式 |
| `outDir` / `rootDir` | out / src | 编译产物目录 |
| `sourceMap` / `declaration` | true | 支持 F5 断点调试 |
| `resolveJsonModule` | true | 可 import JSON |

## 3. 工程约定

- **包管理器**：pnpm workspace（`pnpm-workspace.yaml`）+ npm lock 并存；`.pnpm-store/` 本地缓存不入库
- **模块分区注释**：`extension.ts` 以 `// ──── 数据刷新 / 分时图 Webview / 看板问句管理 / 工具函数 ────` 分节
- **默认值对齐**：常量默认值必须与 package.json 配置默认值一致（如 `DEFAULT_BOARD_AUTO_REFRESH = false`）
- **命名**：命令/配置键 `stock-ticker.` 前缀；类型导出集中于 `stock-data.ts`
- **注释语言**：中文，关键逻辑（动态列、JSONP 剥壳）必须写明容错原因

## 4. 硬约束速查（详见 AGENTS.md）

- 零运行时依赖；不得使用超 ES2020 语法
- 不得使用高于 VS Code 1.74.0 的 API
- `hexin-v.ts` 保持 @ts-nocheck，不做类型改造
- 每次请求新生成 hexin-v；爱问财必须表单编码
