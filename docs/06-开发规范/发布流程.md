# 发布流程

> 最后验证：2026-09-24

stock-ticker 的打包发布步骤与版本时间线。

---

## 1. 版本时间线

| 版本 | 产物大小 | 里程碑 |
|------|----------|--------|
| 0.0.1 | 17.8KB | 初始版本（状态栏 + 基础分时） |
| 0.0.2 | 45.6KB | 看板（板块/个股新高新低）+ 问句管理 |
| 0.0.3 | 46.9KB | 自定义看板、问句管理页、增量更新优化 |

## 2. 打包步骤

```bash
cd stock-ticker
npm run compile   # 1. tsc 编译到 out/
npm run package   # 2. vsce 打包 → stock-ticker-{version}.vsix
```

- 产物位于 `stock-ticker/` 根目录
- `.vscodeignore` 已排除 src/、*.ts、*.map、node_modules、.pnpm-store、*.vsix
- 分发对象：VS Code ≥ 1.74.0，publisher `blowsysun`

## 3. 发布前检查清单

- [ ] `package.json` 版本号已递增（0.0.3 → 0.0.4…）
- [ ] `npm run compile` 无类型错误（strict）
- [ ] `npm run package` 成功生成 vsix，产物大小合理（参考上表量级）
- [ ] 新增命令/快捷键/配置项已同步到 `package.json` contributes
- [ ] `01-需求分析/功能需求清单.md` 命令表与配置表已更新
- [ ] `readme.md`（插件 README）已同步功能与配置
- [ ] 已按 `07-测试用例` 的回归清单完成手动回归
- [ ] vsix 在干净环境（新 VS Code）安装验证：状态栏显示、分时图打开、看板加载

## 4. 回滚

- 保留上一版本 vsix（如 0.0.2 仍在仓库），异常时重新分发旧版本即可
- 配置项向后兼容：读取时 `getBoardQueries` 缺省项回退默认值，删除配置键不会崩溃
