# 功能需求清单

> 最后验证：2026-09-24

本文定义 stock-ticker 插件的功能清单与验收标准（F-01~F-06）。数据源细节见 `05-API文档/外部数据接口.md`。

---

## F-01 状态栏实时监控

描述：底部状态栏右侧展示上证指数当前价格与涨跌幅，红涨绿跌。

- [ ] 状态栏显示 `▲/▼ 上证 {价格} {涨跌幅}%`，红色表示上涨、绿色表示下跌
- [ ] 悬浮 Tooltip 展示开盘价、昨收价、最高/最低价、两市成交额及量比对比
- [ ] 点击状态栏项打开/关闭分时图面板

## F-02 分时图 Webview

描述：侧栏 Canvas 绘制的完整分时图面板。

- [ ] Canvas 绘制分时走势线，红涨绿跌渐变填充
- [ ] 昨收价参考线（虚线）、网格线 + 右侧价格标签（最高/最低/昨收）+ 底部时间轴标签
- [ ] 当前价格圆点标记
- [ ] 自适应窗口大小，支持高 DPI 屏幕
- [ ] 面板内刷新按钮手动触发数据更新
- [ ] 行情数据与看板数据分别增量推送，无需重绘整个页面

## F-03 板块与个股看板

描述：分时图面板中的新高/新低/不创新低看板（板块、个股两个维度）。

- [ ] 板块维度：爱问财「同花顺行业」问答返回的行业指数
- [ ] 个股维度：爱问财问答命中的个股（问句可自定义）
- [ ] 每个维度分「新高」「新低」「不创新低」三组，每组最多展示 8 项，按涨跌幅排序
- [ ] 自定义看板：用户新增的问句在看板页生成对应列表（蓝色标识，最多 8 项），可按「板块/个股」模块归属到对应区域展示

## F-04 问句管理

描述：分时图面板「问句管理」按钮或命令面板进入，自定义爱问财问答语句。

- [ ] 可编辑 6 个默认问句（板块/个股 × 新高/新低/不创新低）
- [ ] 自定义看板每行可选「板块/个股」模块归属；选择后保存，问句自动加入对应看板模块
- [ ] 可开启看板自动刷新并设置频率（秒）
- [ ] 可新增/编辑/删除自定义看板（id/name/question/module）
- [ ] 保存后立即生效并刷新看板；「恢复默认」可还原默认问句

## F-05 智能刷新与交易时段感知

描述：行情自动定时刷新；非交易时段停止请求。

- [ ] 交易时段（09:15–11:35 / 12:55–15:05，北京时间）按 `refreshInterval` 秒自动刷新
- [ ] 非交易时段保留最后一次数据展示，不再发起请求；周末停止刷新
- [ ] 看板默认不随行情定时刷新，仅在手动刷新/问句保存/首次打开分时图时拉取
- [ ] 开启 `boardAutoRefresh` 后，在间隔内且交易时段才自动更新看板

## F-06 配置项

| 配置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `stock-ticker.refreshInterval` | number | 1 | 行情刷新间隔（秒），交易时段内生效 |
| `stock-ticker.boardAutoRefresh` | boolean | false | 是否自动刷新看板（默认关闭） |
| `stock-ticker.boardRefreshInterval` | number | 300 | 看板自动刷新间隔（秒），需开启 autoRefresh 且在交易时段 |
| `stock-ticker.boardQueries` | object | 见下 | 新高/新低/不创新低看板爱问财问句 |
| `stock-ticker.customBoards` | array | `[]` | 自定义看板 `{id, name, question, module}` |

`boardQueries` 默认值：

```json
{
  "sectorHigh": "同花顺行业新高",
  "sectorLow": "同花顺行业新低",
  "sectorNotNewLow": "同花顺行业未创新低",
  "stockHigh": "创60日新高的个股 非ST",
  "stockLow": "创60日新低的个股 非ST",
  "stockNotNewLow": "未创60日新低的个股 非ST"
}
```

- [ ] 修改配置后保存即生效，无需重启

## 命令与快捷键

| 命令 | 标题 | 快捷键（Win / Mac） |
|------|------|---------------------|
| `stock-ticker.showChart` | 上证指数: 查看分时图 | `Ctrl+Shift+V` / `Cmd+Shift+V` |
| `stock-ticker.refresh` | 上证指数: 刷新数据 | `Ctrl+Shift+R` / `Cmd+Shift+R` |
| `stock-ticker.manageBoardQueries` | 上证指数: 管理看板问答语句 | 命令面板 |

## 非需求（明确不做）

- 不提供交易/下单功能
- 不提供自选股管理、多市场（美股/港股）监控
- 不提供历史 K 线图
- 看板标的不再硬编码（旧版 ~100 只清单为历史参考，当前由问句动态决定）
