# Electron 行情浮窗需求

> 最后验证：2026-11-25

Windows 用户可独立启动桌面浮窗，在使用其他应用时查看上证指数与沪深两市成交额变化。以下验收条件依据当前实现整理。

| 功能 | 验收条件 |
|---|---|
| 常驻展示 | 启动后在主屏工作区右下角显示置顶行情条，启动时保留当前应用焦点，任务栏隐藏浮窗入口。重复启动唤回现有浮窗。 |
| 行情摘要 | 显示上证指数点位、相对昨收的涨跌幅，以及沪深两市累计成交额较上一交易日同期的差值绝对值。点位与涨跌幅保留两位小数，缩放量按整数亿元显示，放量红、缩量绿，差值为零时隐藏缩放量。 |
| 详情 | 悬停、点击或键盘聚焦行情按钮时展开。表格展示今日与上一交易日的点位、涨跌、缩放量和成交额，末行分别展示 5 日和 60 日平均成交额。昨日点位取昨收，成交额沿用行情服务提供的昨日同期口径，昨日涨跌与缩放量按已完成交易日计算，缺失的历史值以「—」显示。 |
| 展开与收起 | 优先向下展开，下方空间不足且上方空间更大时向上展开。指针移出约 140 ms 后收起，便于移入详情区。按 Escape 后收起并将焦点放回行情按钮。 |
| 跨屏移动 | 用左侧手柄拖动浮窗，可跨显示器移动。收起态按可见行情条限制位置，可拖到任务栏边缘。展开态按完整窗口限制位置，收起时保留拖动后的位置。拔屏或工作区尺寸变化后重新定位。 |
| 行情刷新 | 启动即拉取。每秒检查一次，北京时间工作日 09:15–11:35 和 12:55–15:05 按分钟判断自动拉取，周末跳过交易时段。时段外优先显示上次成功行情，首次拉取或上次请求失败时仍可请求。详情中的刷新按钮可在时段外主动请求，已有请求进行时避免重复拉取。 |
| 失败与退出 | 首次获取失败显示「获取失败」。已有成功行情时保留该行情并显示警示。详情中的关闭按钮关闭浮窗并退出应用。 |
