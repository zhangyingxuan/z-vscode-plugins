# Stock Ticker - 指数观测

在 VS Code 中实时监控股票市场行情，支持状态栏快速查看和分时图详情面板。

## 功能特性

- **状态栏实时行情** — 底部状态栏右侧展示上证指数当前价格、涨跌幅，红涨绿跌
- **分时图面板** — 一键打开侧栏 Canvas 绘制的完整分时图，包含板块和个股看板
- **板块看板** — 实时展示新高/新低/不创新低板块及个股
- **智能刷新** — 交易时段自动定时刷新，非交易时段休眠节省资源
- **悬浮详情** — 鼠标悬停查看开盘价、最高/最低价、成交额等详细信息

## 使用方法

### 状态栏查看

安装后，状态栏右侧会自动显示上证指数实时行情：

```
▲ 上证 3285.45 +1.23%
```

- 点击状态栏项可打开/关闭分时图面板
- 鼠标悬停查看详细信息

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+V` | 打开/关闭分时图面板 |
| `Ctrl+Shift+R` | 手动刷新行情数据 |

### 命令面板

按 `Ctrl+Shift+P` 打开命令面板，输入以下命令：

- `上证指数: 查看分时图` — 打开/关闭分时图面板
- `上证指数: 刷新数据` — 手动刷新行情数据

## 分时图面板

分时图面板包含：

- **价格走势图** — Canvas 绘制的日内分时曲线
- **关键价格标注** — 自动标注最高价、最低价、昨收价
- **成交信息** — 两市成交额及与上日同时刻对比
- **板块看板** — 新高/新低板块 TOP 8
- **个股看板** — 新高/新低个股 TOP 8

## 配置项

| 配置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `stock-ticker.refreshInterval` | `number` | `1` | 数据刷新间隔（秒），交易时段内生效 |

## 数据源

使用 [东方财富 Push API](https://push2.eastmoney.com)（免费、无需鉴权）：

- 实时行情（价格/涨跌幅/成交量）
- 当日分时曲线数据
- 板块和个股涨跌统计
