# Stock Ticker - 指数观测

在 VS Code 中实时监控上证指数与两市成交额，支持状态栏快速查看和分时图详情面板。

## 功能特性

- **状态栏实时行情** — 底部状态栏右侧展示上证指数点位 + 涨跌幅，以及较昨日同期放量/缩量额（不带单位，红涨绿跌）
- **分时图面板** — 一键打开侧栏 Canvas 绘制的两市成交额分时图（当日 vs 昨日同时刻曲线），包含板块和个股看板
- **板块看板** — 实时展示新高/新低板块及个股，支持用户自定义看板（问句管理页增删改）
- **问句管理** — 分时图面板或命令面板进入，可自定义爱问财问答语句、看板自动刷新开关与频率（秒），保存即生效
- **智能刷新** — 交易时段自动定时刷新；新高/新低看板默认不自动刷新（可在设置开启，避免无谓请求）
- **悬浮详情** — 鼠标悬停查看指数点数、涨跌额、成交额、涨跌幅、预测全天成交额及近 5/60 日均额

## 使用方法

### 状态栏查看

安装后，状态栏右侧会自动显示上证指数实时行情：

```
▲ 上证 3820.82 -1.74% 放量924
```

- 点击状态栏项可打开/关闭分时图面板
- 鼠标悬停查看指数点数、成交额、涨跌幅等详细信息

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+V` | 打开/关闭分时图面板 |
| `Ctrl+Shift+R` | 手动刷新行情数据 |
| `Ctrl+Shift+P` → `上证指数: 管理看板问答语句` | 编辑新高/新低看板的爱问财问句 |

### 命令面板

按 `Ctrl+Shift+P` 打开命令面板，输入以下命令：

- `上证指数: 查看分时图` — 打开/关闭分时图面板
- `上证指数: 刷新数据` — 手动刷新行情数据

## 分时图面板

分时图面板包含：

- **成交额分时图** — Canvas 绘制的两市成交额日内曲线（当日累计 vs 昨日同时刻）
- **指数行情** — 上证指数点位、涨跌幅、开高低与昨收
- **成交信息** — 当日/昨日成交额、较昨日放量/缩量、预测全天成交额、近 60 日均额
- **更新时间** — 指数与看板模块各自展示最近刷新时间
- **板块看板** — 新高/新低板块 TOP 8
- **个股看板** — 新高/新低个股 TOP 8

## 配置项

| 配置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `stock-ticker.refreshInterval` | `number` | `1` | 行情数据刷新间隔（秒），交易时段内生效 |
| `stock-ticker.boardAutoRefresh` | `boolean` | `false` | 是否自动刷新新高/新低看板（默认关闭） |
| `stock-ticker.boardRefreshInterval` | `number` | `300` | 看板自动刷新间隔（秒），需开启 `boardAutoRefresh` 且处于交易时段 |
| `stock-ticker.boardQueries` | `object` | 见下 | 新高/新低看板的爱问财问答语句（分时图面板「问句管理」可编辑） |
| `stock-ticker.customBoards` | `array` | `[]` | 用户自定义看板（`{id, name, question}`），问句管理页可增删改，保存后在看板页生成对应列表 |

`boardQueries` 默认值：

```json
{
  "sectorHigh": "同花顺行业新高",
  "sectorLow": "同花顺行业新低",
  "stockHigh": "创60日新高的个股 非ST",
  "stockLow": "创60日新低的个股 非ST"
}
```

## 数据源

使用同花顺接口：

- 上证指数实时点位 / 开高低 / 昨收（`d.10jqka.com.cn/v6/time` 分时线快照）
- 两市成交额分时（`dq.10jqka.com.cn` fuyao `chart_key=turnover_minute`）：当日/昨日同时刻累计成交额 + 较昨日变动 + 预测全天
- 两市成交额日K对比（`chart_key=turnover_day`）：当日成交额 vs 近 5/60 日均额
- 新高/新低板块与个股看板（爱问财 `iwencai.com` 自然语言查询）
